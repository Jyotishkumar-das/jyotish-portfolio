JYOTISH KUMAR DAS — REACT PORTFOLIO

Requirements:
- Node.js (LTS)
- npm

Run locally:
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open Terminal in the project folder.
4. Run: npm install
5. Run: npm run dev
6. Open the local URL shown by Vite (usually http://localhost:5173).

Included:
- React + Vite source
- Responsive design, animated role typing, scroll reveal, animated project cards
- Dark/light theme toggle
- Supplied portrait photo at public/jyotish.jpg
- Supplied resume PDF at public/Jyotish-Kumar-Das-Resume.pdf
- Four live project links: ExpenseTracker, Forever E-Commerce, JobConnect, QuickMart
- Skills, internships, education, certifications, and contact section

Before deploying:
- Test all project links and the resume link.
- Confirm all details and skill descriptions are accurate.
- Deploy the project to Vercel or Netlify.
